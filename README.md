# astrbot_plugin_persona_switch

用指令给**当前会话**换人格的 AstrBot 插件。群里 @ 一下或者敲个指令就能换，不用进 WebUI 翻菜单。

## 指令

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `/人格列表` | 人格list / persona_list | 列出所有人格与编号，标出当前生效的那个 |
| `/人格切换 <序号或名称> [分钟]` | 换人格 / 切换人格 / 人格设置 | 把**当前会话**切到指定人格；带分钟数就是限时切换，到期自动还原并在群里发提示 |
| `/人格当前` | 当前人格 / 人格查看 | 看当前会话生效的人格，以及限时切换剩余时间 |
| `/人格重置` | 人格默认 / 清除人格 | 清掉本会话的人格指定，回到全局默认 |

示例：

```
/人格切换 3            # 按列表编号切
/人格切换 哈基米        # 按名称切（支持唯一模糊匹配）
/人格切换 哈基米 30     # 30 分钟后自动还原
/人格重置
```

## 生效范围与时机

- 作用域是**会话级**（`unified_msg_origin`），也就是「这个群」或「这个人的私聊」，不影响别的群。
- AstrBot 每次请求都会重新解析人格，所以切换后**下一条消息**就生效，不用重启、不用重载插件。
- 与 WebUI「会话管理 → 修改人格」写的是同一份数据（`shared_preferences` 里 scope=`umo`、key=`session_service_config`、字段 `persona_id`）。WebUI 改的插件认，插件改的 WebUI 也看得见，两边不打架。

## 配置项

见 `_conf_schema.json`，在 WebUI 插件配置里改：

- `admin_only`：仅管理员可切换（默认开）
- `allow_temporary`：是否允许限时切换（默认开）
- `max_temp_minutes`：限时切换最长分钟数（默认 720）
- `notify_on_restore`：限时切换到期时是否发「切换结束」提示（默认开）
- `show_prompt_preview`：`/人格列表` 是否附带人格提示词预览（默认关，人格含私密设定时别开）
- `max_list_rows`：列表最多显示条数（默认 50）

## 安装

把本目录放进 `data/plugins/` 下，然后：

- WebUI → 插件管理 → 点重载；或
- 执行 `/plugin reload astrbot_plugin_persona_switch`

日志里出现 `Loaded N personas.` 就说明能读到人格，指令即可用。

## 已知边界

- 只影响走 AstrBot agent / LLM 流程的回复；别的插件自己硬编码的提示词管不到。
- 限时切换的任务存在内存里，进程重启后不会自动还原，会话会停在切换后的人格上，需要的话 `/人格重置` 一下；同理重启后也不会补发「切换结束」提示。
- 人格标识即 WebUI 里的人格名（`persona_id`）；系统保留的 `default` 是内置默认人格，可切不可删。

## 想扩展的话

`main.py` 里的 `_set_persona_for_session()` 是唯一的写入口，要做「按人切换」「随机人格」「每周轮换」都在这上面搭就行。想让 LLM 自己决定换人格，可以加一个 `@filter.llm_tool`，但要留意群聊里任何人都能间接触发的风险，建议配合管理员校验。
